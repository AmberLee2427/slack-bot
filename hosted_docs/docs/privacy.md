# Privacy and acceptable use

Nancy processes search terms, document identifiers, and tool arguments sent by
your MCP client. Operational records may include an API-key prefix, IP address,
timestamp, and request metadata for reliability and abuse prevention.

- Do not send secrets, unpublished participant data, or sensitive personal
  information in queries.
- Your MCP client and model provider process the conversation under their own
  policies.
- Treat retrieved material according to its source license and collaboration
  rules.
- Personal API keys may be revoked if shared or abused.

Nancy does not sell usage data. To request key revocation or deletion of
associated records, contact `amber@malpas.nz`.

For implementation and self-hosting behavior, see the
[Nancy Brain package documentation](https://nancy-docs.malpas.nz/).
